# ProfileSmith 1.5.0

## 分发方式调整

- 改为按芯片分别提供安装包：Apple 芯片（M 系列）下载 `ProfileSmith_V_1.5.0_arm64.dmg`，Intel 芯片下载 `ProfileSmith_V_1.5.0_x86_64.dmg`，体积约为原通用包的一半。
- 应用内自动更新会按当前 Mac 的芯片选择对应的安装包；旧版通用包用户升级后会自动切换为匹配的版本。

## 新功能

- 自动监听描述文件目录，Xcode 下载、删除或替换描述文件后列表自动刷新，无需手动点击“刷新”。
- 新增“文件 → 清理过期描述文件…”，确认后把所有已过期的描述文件一次性移到废纸篓。
- 列表右键菜单新增“复制 UUID”和“复制 Bundle ID”，支持多选批量复制。
- 在列表中按 Delete 键可把选中的描述文件移到废纸篓（会先弹窗确认）。
- 首次启动时界面语言跟随系统，后续仍可在偏好设置中切换。

## 问题修复

- 修复 Mac 的 Developer ID 描述文件被识别为“分发（App Store）”的问题，现在显示为“分发（Developer ID）”。
- 修复 Mac 描述文件的 Bundle ID 始终为空的问题。
- 修复单个描述文件损坏会导致整次扫描失败、列表无法刷新的问题；损坏文件会被跳过并在状态栏提示数量。
- 修复搜索只能匹配单词开头的问题，现在可以搜索名称或 Bundle ID 中间的任意片段；输入 `%`、`_` 不再匹配全部结果。
- 修复导出证书时选择 `.cer` 仍写出 PEM 文本、钥匙串无法直接导入的问题；`.cer` 现在为 DER 格式，`.pem` 为文本格式。
- 修复导出描述文件时目标恰好是源文件本身会把源文件删除的问题。
- 修复从未安装过描述文件的 Mac 上导入失败（目标目录不存在）的问题。
- 修复同时打开多个预览窗口时，较早的窗口内容变为空白的问题。
- 修复右键菜单中“预览”“导出”等只支持单选的操作在多选时仍可点击的问题。
- 修复分隔条位置在重启后不被记住的问题。
- 概要页中的 Entitlements 布尔值显示为 true / false，数组显示为单行列表，不再显示为 1 / 0 和多行括号。

## 性能与稳定性

- 预览 IPA 时只解压 Info.plist 与内嵌描述文件，并在后台完成，大体积 IPA 不再卡住界面。
- 后台扫描与界面查询之间的数据竞争已消除；日期格式化与本地化文案读取改为复用实例。
- 重命名备份目录改为在需要时才创建。
